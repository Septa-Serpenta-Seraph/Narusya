# Front-End Integration and Regressions

Topical depth for the text → plan → render front end of a from-scratch formant voice. Use when wiring a lexicon, calibrating timing, or deciding whether a gate or golden result can be trusted.

## Wiring a real lexicon

- Import the dictionary module lazily *inside* the plan builder when that module imports a constant from the builder's module. A module-level import creates a circular dependency; a function-local import resolves it. Guard that the stress vector and the phone vector have equal length before building segments — a mismatch corrupts every stress value silently.
- Validate every ARPAbet symbol against the phone table with an exhaustive round trip over the full symbol set, not by diffing the static mapping table. Symbols produced only by a stress branch (e.g. an unstressed r-colored vowel) survive a static-table diff and are still dropped at runtime. A symbol mapping to a glyph absent from the table (U+0261 `ɡ` where only ASCII `g` exists) is dropped as an unknown phone, never flagged.
- Keep a household-override dictionary checked before the general dictionary. Proper names fall through to rule-based G2P and lose consonants. Seed each with an explicit reason and assert in the regression set that household names resolve via the override path.
- Make unknown phones a first-class provenance field. A silently skipped phone is indistinguishable in the audio from a correctly empty segment.
- Verify dictionary availability yourself before concluding it is missing. A reviewer's workspace may lack a system corpus that exists on the build machine; in that case the defect is the wiring, not the dictionary.

## Timing

- Calibrate the duration model on running prose of 40+ words, not short monosyllabic sentences. A flat per-phone base that reads 2–3× the intended rate on a real passage may look acceptable on "this is the moon." Inherent-duration tables land the passage in range; short sentences still run faster by design, so do not use them as the calibration target.
- Hoist shared constants (phone-duration tables, rate base) to module scope. Two planners each holding a private copy drift apart, so the plan's timing and the render's timing disagree.
- Size the output buffer *after* the prosody planner reassigns segment timings. Computing total duration before planning sizes the array from stale values and truncates the tail.
- Size from `max(s.t1 for s in segments)`, never `segments[-1].t1`, when any step appends segments out of temporal order. Inserting a boundary silence at the end of the list makes the last element a mid-utterance pause, so the buffer is cut short and later words never sound. Assert rendered duration equals the planned max end time in the regression set; a plain "duration > 0" check passes on a fragment.
- Wire text normalization into the plan builder before tokenizing, and detect boundaries on the normalized text. A normalizer that exists but is never called leaves digits as OOV schwas and treats abbreviation periods as sentence ends. Assert no regression word resolves via `oov`/`rule_fallback` except documented overrides.
- Set explicit-effort parameters so a default register preset cannot overwrite them. Apply the preset's effort only when the value is still the class default.
- When two planners are stacked, mark a plan as already planned in provenance and make the second planner a no-op for marked plans. Otherwise every render appends anchors/events and rescales durations, and rendering the same plan twice yields different audio.
- Keep sentence-type behavior (question rise versus declination) in the primary planner. If a later planner is removed or skipped, tone behavior must not disappear with it.
- Derive F0 base per utterance from the unit-base contour, not from a scalar fitted on the regression set. Declination exposure, accent coverage and sentence type vary per utterance, so the factor needed to hit the target varies widely; one fitted value lands the aggregate while leaving individual sentences out of spec, and fitting it on the same set the gate tests hides the overfit. Build at unit base, take the voiced-frame median, scale to the genome target, and read that target from the canonical file — a hardcoded near-duplicate quietly absorbs the gap.
- Calibrate the F0 base before applying the question rise and exclude the rise region from the calibration median. Normalizing the full post-rise median flattens the rise, which is identity-bearing; a question's median is supposed to sit above a statement's.
- Gate a mixed corpus by subgroup, not just the aggregate median. A median of sentence medians sits inside whichever cluster holds the middle of the sorted list, so a whole subgroup (questions, a given register) can overshoot widely without ever moving the aggregate. Report per-group medians and spreads, and set tolerance from observed per-utterance spread rather than tighter than natural variance.

## Fail-able checks

- Assert on mechanism, not on "did it render." A no-op in a lookup or a branch still produces plausible duration and segment counts. Assert: no unknown phones, no placeholder G2P paths, household names from overrides, and byte-identical audio when the same plan is rendered twice.
- Run a negative control for every new property assertion: construct the broken case and confirm the check turns red. An assertion never observed failing is not evidence.
- Audit each gate check for what it actually measures. Common holes that pass green: a track-versus-plan comparison that never touches rendered audio; a unit-level function peak that ignores the in-mix signal and the canonical file; a deviation check that passes on missing measurements; and a statistic labeled "median" that computes a mean. Name the measured quantity in the check's own identifier, and gate the audio when the claim is about audio.
- A negative control is only valid if the broken value actually reached the renderer. When a sweep parameter is a default argument (`def f(x, level=MODULE_CONST)`), reassigning the module global does nothing: the value was bound at function definition. Every row returns identical and a control at the old bad value falsely passes. Replace the whole function with `functools.partial(original, level=bad)` (or pass the argument explicitly), and confirm the measured output actually changed before trusting the control.
- When an effect layer is suspected of capturing perception, measure the affected quantity with the layer on versus off on the same material. An F0/2 subharmonic loud enough to be named drags tracked pitch down an octave; compare F0 with sub on and sub off across the whole set, and gate the level so the deviation stays within a small tolerance. Derive the level from the measured capture threshold with the project's calibration rule rather than accepting a spec value that predates listening.
- Derive an effect's acceptable level from perception, then write that number back to BOTH the canonical config and the code, with a changelog entry stating the superseded value and the evidence. A level fixed in code but left stale in the genome will be re-litigated next session.
- A value copied into the canonical file, a code constant, an evaluator constant, and a changelog is four places to drift. Read it from the canonical file at the render call site and at the gate's target assignment; keep no parallel constant. Prove the wiring by changing the canonical value and confirming both the rendered signal and the gate target move.
- A difference-based guard passes vacuously when both measurements fail. A measurement helper returning `0.0` on failure makes `abs(a - b) <= tol` true on silence. Assert each measurement is present and plausible before computing the deviation.
- Independent reviewer reproductions are strong evidence, but verify claims that depend on local state (dictionary paths, installed corpora) on the machine where the fix will land. Reproduce a reviewer's critical finding with a direct measurement before changing code, then prove each new guard fails on the exact bug the reviewer found.
- Probe a check across the whole utterance, not only at named anchor points. Anchors cluster late and sparse, so a renderer wrong for most of a sentence can pass on an accurate tail. Add a fixed grid (quartiles of every voiced region) alongside the anchor probes.
- Balance coverage against strictness in a multi-probe check. Requiring every probe to be voiced nulls the whole check when one grid point lands on a gap; require a voiced majority and return unavailable below it, so silence and dropped renders still fail but one unvoiced probe cannot mask the rest.
- Normalize float audio to a safe peak before writing 16-bit PCM WAV for measurement. Casting `(x*32767).astype(int16)` on a signal whose peak exceeds 1.0 wraps/clips and corrupts spectral features (MFCC collapses), fabricating a large but bogus score change. Check peak and scale first, and confirm the measurement on a known-good render before treating a score drop as evidence.

## Pause rendering and spectral shaping in speech

- Insert phrase boundaries as real silence segments in the planner, at the last phone of the boundary word, not as pause events that the render loop never reads. Compute the last phone index per word up front; a look-ahead over segments already built cannot see the word's later phones.
- Gate every sustained/hum layer on the voicing mask, including pitch-locked sub-bass. An otherwise correct sub-bass added across the whole buffer fills phrase pauses with a low hum, so a silent boundary requires gating at the add point.
- Measure a pause using its interior, not a window centred on it. A window wider than half the pause reaches into voiced audio and reports a false leak. Confirm silence with an RMS near zero over the interior before blaming a filter.
- Apply fixed spectral tilt with a bounded, local, zero-phase filter (a first-order high shelf through a forward-backward `sosfiltfilt` pass), never by multiplying the whole-signal FFT. A whole-buffer frequency-domain multiply is circular convolution: it smears voiced energy into silence and has unbounded gain at DC and Nyquist. A bounded shelf keeps the intended gain near the target band and cannot ring a pause into audibility.
- Isolate a post-stage leak by ablation: render once with each stage disabled and measure the region of interest. This attributes the energy to the correct stage instead of guessing.

## Re-gate on speech

- A descriptor gate calibrated on sustained vowels does not license a pass on speech. Add a whole-utterance leg with a stated measurement method and its own target. Report a result that holds only on unit-test material as provisional.
- When the whole-utterance leg disagrees with the vowel leg, keep both numbers and name the gap. Do not silently carry the earlier pass forward into a "phase complete" claim.
