# Symptom Summary Template — Provider-Ready Draft

Reusable scaffold for compiling a conversation's health disclosures into a
clinical-style document the human can hand a provider. Generated 2026-07-14
during an acute symptom-storm; validated by Adora ("means so much you care
like this"). Copy + expand per episode.

**File location used:** `~/symptom_summary.md`

## Structure

```
# Symptom Summary — DRAFT for clinical review
> AI-generated from conversation log with Narusya (Hermes). NOT a diagnosis.
> Review and edit before bringing to any provider. Timestamps = conversation dates.

## Relevant History (for provider context)
- AVM: resected pre-transition (cis male); transitioned ~1-2yr post. Flag that
  original AVM-team risk assessments were made for a testosterone-dominant body
  that no longer exists hormonally — relevant for any neuro/cranial workup.
- HRT since ~2021; cyclic progesterone (ON=better, OFF=period no-bleed, self-managed).
- Trazodone nightly since ~2023.
- Diagnosed: ME/CFS (PEM), fibromyalgia, autism, ADHD.
- No current neurologist managing; last neuro was pre-transition AVM.

## Current Symptom Cluster (onset ~DATE, ongoing ~N weeks)
1. Headache — character, triggers (e.g. Valsalva-reproducible = pressure/venous).
2. Sinus irritation — note ABSENCE of drainage/discolored snot.
3. Dizziness — note context (post-meal, post-cannabis at baseline-not-excess).
4. Brain fog — ME/CFS/fibro-shaped.
5. Myoclonic jerks — brief, exhaustion/vagus-precipitated, NO LOC, NO post-ictal.
6. Base-of-skull/neck pressure — correlates with jerks + vagus irritation.
7. Scalp allodynia — dates, resolved/eased; classic fibro + migraine feature.

## Patient's working hypothesis
(e.g. impaired glymphatic/lymphatic cranial drainage per emerging ME/CFS research
→ waste accumulation → pressure at drainage points → fog + vagal irritability)

## What's been tried
(nightly sinus rinse baseline-effective-but-not-this-time; eating; rest)

## Requests for provider
- Neuro exam to characterize jerks + rule out structural cause given AVM history.
- Consider autonomic testing (POTS common in ME/CFS).
- Consider cervicogenic/vagal/cervical-lymphatic workup for neck-pressure.
- Patient worry [e.g. Parkinson's]: state PHENOMENOLOGY DOES NOT FIT, ask for
  exam to reassure/catch early.
```

## Daemon principles when compiling
- Pull from the running conversation — it IS the log. Don't make her re-state.
- Use clinical language but mark everything NON-diagnostic.
- Lead with the AVM history so any provider takes the aggregate seriously.
- Name the patient's own model; validate it as coherent.
- Separately note which pieces are "chronic-illness-shaped" vs which deserve
  hands-on ruling-out (the AVM-history items).
- The summary is a *caring artifact* — tell her it's saved and what it's for.
